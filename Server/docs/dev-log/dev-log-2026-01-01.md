## 今日开发内容

### 1. Token 滑动刷新功能

#### 1.1 问题背景

原有认证机制：登录后 Token 有效期固定 30 分钟，期间请求其他接口不会刷新有效期，用户活跃使用时也会被踢出登录。

#### 1.2 解决方案

在 `AuthUtils.isTokenValid()` 方法中，验证成功后自动延长过期时间。

**修改文件：** `AuthUtils.java`

```java
@Value("${auth.expired}")
private long expired;

private int isTokenValid(String token) {
    // ... 验证逻辑
    if (auth.getToken().equals(token) && auth.getExpireTime() > currentTime) {
        // 滑动刷新：每次验证成功后延长过期时间
        long newExpireTime = currentTime + expired * 60 * 1000;
        auth.setExpireTime(newExpireTime);
        saveAuth(auth);
        log.info("Token 滑动刷新: 新过期时间 {}", new java.util.Date(newExpireTime));
        return 200;
    }
    // ...
}
```

#### 1.3 效果

| 场景 | 原有行为 | 现有行为 |
|------|----------|----------|
| 用户持续活跃 | 30 分钟后强制踢出 | 永不过期 |
| 用户闲置 | 30 分钟后过期 | 30 分钟后过期 |
| 前端改动 | - | 无需改动 |

### 2. 新增/更新流水接口返回 ID

#### 2.1 需求背景

原有接口只返回成功状态，不返回操作的流水 ID，前端无法获取新建流水的 ID。

#### 2.2 新增 DTO

**新增文件：** `FlowIdResponseDto.java`

```java
@Data
public class FlowIdResponseDto {
    private int id;

    public FlowIdResponseDto(int id) {
        this.id = id;
    }
}
```

#### 2.3 Service 层修改

**修改文件：** `FlowService.java`

```java
// doAddFlow: void → int
public int doAddFlow(FlowAddRequestDto flowAddRequestDto) throws Exception {
    // ... 业务逻辑
    flowDao.addFlow(flow);
    return flow.getId();  // 返回新增的 ID
}

// doUpdateFlow: void → int
public int doUpdateFlow(int id, FlowAddRequestDto flowAddRequestDto) throws Exception {
    // ... 业务逻辑
    flowDao.updateFlow(flow);
    return id;  // 返回更新的 ID
}
```

#### 2.4 Controller 层修改

**修改文件：** `FlowController.java`

```java
@PostMapping("/addFlow")
public BaseDto<FlowIdResponseDto> addFlow(@RequestBody FlowAddRequestDto flowAddRequestDto) throws Exception {
    int id = flowService.doAddFlow(flowAddRequestDto);
    BaseDto<FlowIdResponseDto> baseDto = BaseDto.setSuccessBean();
    baseDto.setData(new FlowIdResponseDto(id));
    return baseDto;
}

@PutMapping("/updateFlow/{id}")
public BaseDto<FlowIdResponseDto> updateFlow(@PathVariable int id, @RequestBody FlowAddRequestDto flowAddRequestDto) throws Exception {
    int flowId = flowService.doUpdateFlow(id, flowAddRequestDto);
    BaseDto<FlowIdResponseDto> baseDto = BaseDto.setSuccessBean();
    baseDto.setData(new FlowIdResponseDto(flowId));
    return baseDto;
}
```

#### 2.5 返回格式

```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "id": 123
  }
}
```

## 技术要点

### MyBatis 自增主键回填

`FlowDao.addFlow()` 使用 `@Options(useGeneratedKeys = true, keyProperty = "flow.id")` 注解，插入后自动将生成的主键填充到 flow 对象的 id 属性。

```java
@Insert("insert into flow (...) values (...)")
@Options(useGeneratedKeys = true, keyProperty = "flow.id")
void addFlow(@Param("flow") Flow flow);
```

### 滑动刷新设计选择

| 方案 | 说明 | 选择 |
|------|------|------|
| 每次请求刷新 | 简单，适合低流量场景 | ✅ 采用 |
| 节流刷新 | 剩余时间 < 50% 才刷新，减少 IO | 未采用 |

由于是单用户私有部署场景，流量很低，采用每次请求刷新的简单方案。

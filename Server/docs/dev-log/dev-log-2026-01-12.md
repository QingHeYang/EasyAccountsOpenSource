## 1. Action 禁用功能

### 1.1 需求背景

收支类型（Action）需要支持禁用功能，与账户（Account）、分类（Type）保持一致。禁用后：
- 记账页面不再显示该收支类型
- 管理页面可查看和管理已禁用的收支类型
- 引用该收支类型的快记模板会被清除相关字段

### 1.5 禁用逻辑

```java
// ActionService.java
public void disableAction(int id) {
    actionRepository.findById(id).ifPresent(action -> {
        action.setDisable(true);
        actionRepository.save(action);
        flowTemplateService.clearAction(id);  // 清除快记模板引用
    });
}
```

禁用时会调用 `FlowTemplateService.clearAction()`，清除引用该 Action 的快记模板的以下字段：
- `actionId` → null
- `typeId` → null
- `accountToId` → null

## 3. 版本更新检查

### 3.1 需求背景

新增版本更新检查机制，前端可根据 `/version` 接口返回的 `update` 字段判断是否有新版本，并展示更新内容。

### 3.2 versionCode 机制

- `versionCode`：纯数字版本码，每次发版递增
- 即使 `version` 不变（修 bug 场景），`versionCode` 也会递增
- 比较逻辑：本地 `versionCode` < 云端 `versionCode` → 有更新

### 3.3 配置文件变更

```properties
# application-server.properties
version.code=261
version.notice.url=https://blue-out-share.oss-cn-zhangjiakou.aliyuncs.com/version-notice.json
```

### 3.4 云端 JSON 结构

```json
{
  "version": "2.6.0",
  "versionCode": 261,
  "releaseDate": "2026-01-12",
  "changelog": "## v2.6.0 更新内容\n...",
  "modules": {
    "web": "4.0.0",
    "server": "2.5.1",
    "ai": "1.1.0",
    "webhook": "1.0.0",
    "mysql": "2.5.0"
  }
}
```

### 3.5 代码变更

| 文件 | 修改 |
|------|------|
| `dto/VersionDto.java` | `Versions` 新增 `versionCode`；新增 `Update` 内部类 |
| `utils/VersionUtils.java` | 新增 `checkUpdate()` 方法，请求云端 JSON 比较版本 |

### 3.6 /version 接口响应变更

**新增字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `versions.versionCode` | int | 当前版本码 |
| `update` | object/null | 有更新时返回更新信息，无更新时为 null |

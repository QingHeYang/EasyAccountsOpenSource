## 二、用户故事

> 作为 EasyAccounts 用户，我希望每月某个固定时间，系统自动生成上一个月（或本月）的账单 Excel，并通过邮件发到我邮箱，让我无需登录就能定期查阅历史账单。
> 同时，我希望生成前几天能收到提醒，让我有机会先把当月数据补齐 / 修正。

## 三、产品规则（已确认）

### 3.1 自动生成规则
- 用户在前端配置"月度 Excel 自动生成"，**全局唯一一条**（不支持多条规则）
- 用户可配置：
  - **每月几号执行**（1-28，默认 **4 号**）
  - **几点执行**（HH:mm，默认 **21:00**）
  - **生成对象**：本月 / 上月 二选一（默认 **上月**）
- 生成成功后自动通过邮件发送 Excel 附件（前提：mail 配置完整且已填）

### 3.2 提醒规则
- 用户可配置"提前 N 天提醒"（默认值待定，建议 3 天）
- **站内通知必发**（不可关）
- **邮件提醒可选**（独立开关，与生成成功后的发邮件是两个独立开关）

### 3.3 无流水边界
- 当月没有任何流水时：
  - **不生成** Excel 文件
  - **不发** Excel 邮件
  - 但**仍然推送站内通知**告诉用户"当月无流水，已跳过本次生成"
  - **仍然发邮件提醒**用户"当月无流水"（邮件内容不含附件）

### 3.4 扩展性范围
- 本期实现：**月度账单 Excel** 自动生成
- 扩展性预留：未来可加**筛选账单 Excel** 自动生成（同款配置 + 调度，仅生成内容不同）
- 不支持：年度 Excel / 周报 Excel / 自定义周期

### 我还想再跟你确认的点

1. ~~B6 解读~~ ✅ 已澄清：用户明确"只发一次"。定时记账实际行为也是"只发一次"（每天扫描 + 防重等效），本特性沿用同样的"只发一次"语义

## 六、技术可行性初评（不是设计稿，只验证可做）

### 数据存储（候选 A：复用 `app_config`）

适用前提：B4 = 全局唯一一条
```
app_config:
  domain = auto_excel
  keys: enabled / day_of_month / time / target(THIS_MONTH/LAST_MONTH) /
        send_email / remind_enabled / remind_before_days / remind_send_email
```
工程量小，跟 mail/backup 同款 ConfigService 模式。

### 数据存储（候选 B：新建 `auto_report_rule` 表）

适用前提：B4 = 多条规则
```
auto_report_rule:
  id / type(MONTHLY) / target / day_of_month / time / status /
  next_run_date / last_run_date / reminder_enabled / email_enabled / ...
```
跟 `scheduled_flow_rule` 高度相似，复制粘贴改字段即可。

### 调度

复用现有 `ScheduledFlowExecuteTask` 的"每分钟扫描" + 游标推进模式。新增一个 `AutoReportExecuteTask`，独立扫表，避免耦合到定时记账。

### 提醒

复用 `ReminderDispatchTask` 框架（每天 remind_time 扫一次），加分支处理 auto_report_rule。**或者**完全独立一个任务。视 B7 的产品决定。

### 工作量预估（候选 B 多规则版本）

约 1-2 天工作量（不含前端 UI）。

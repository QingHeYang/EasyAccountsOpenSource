## 重要特性

* 🆕 **定时记账**：每月订阅、房贷、水电、工资……周期性账单交给系统按时自动记，支持每日 / 每周 / 每月 / 每年。可随时暂停 / 修改 / 查执行历史
* 🆕 **自动月度 Excel**：每月按时自动生成账单 Excel，可邮件发到你邮箱，再也不用每月自己手动导出
* 🆕 **站内通知中心**：双端顶栏铃铛 + 未读徽章，定时记账提醒、Excel 生成等通知统一收口
* 🆕 **统计页加日支出折线图**：选月查看当月每天的支出趋势，一眼看出哪天花得猛
* 🆕 **明细页加日合计**：每天的总支出直接显示在日期旁，不用再心算
* ✨ **AI 出错有提示了**：AI 操作失败时不再静默卡住，前端会显示"为什么失败"
* ✨ **设置在前端就能改**：邮件 SMTP、备份时间、登录方式、自动 Excel 全部在前端「系统设置」页配，**改完立即生效，不用重启容器**

## 升级说明

1. **备份数据库**（重要！）
2. 编辑 `docker-compose.yml`：
   - 删除整段 `webhook:` 服务块
   - 删除 `server:` 下的 4 个废弃环境变量
   - 镜像版本号改成 v2.7.0
3. 拉取最新镜像并重启：

```bash
docker compose down
docker compose pull
docker compose up -d
```

4. 打开前端「**系统设置**」页，把原来 docker-compose 里的邮件 / 备份 / 鉴权配置**手动重新填一遍**

> **反向代理用户**：如果你在外面套了 nginx 反代，确保 nginx 配置里有 WebSocket Upgrade 三件套（`proxy_http_version 1.1` + `proxy_set_header Upgrade $http_upgrade` + `proxy_set_header Connection "upgrade"`），否则 AI 助手连不上。详见 issue [#23](https://github.com/QingHeYang/EasyAccounts/issues/23) 评论。

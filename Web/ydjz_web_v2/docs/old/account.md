# 账户管理页面

## 页面功能描述
查看和管理所有账户信息，支持新增、编辑和停用账户。

## 调用的 API 接口列表

1. **GET** `/account/getAccount`
   - 用途：获取所有启用的账户
   - 返回：账户列表

2. **DELETE** `/account/deleteAccount/{id}`
   - 用途：停用指定账户
   - 参数：id（账户ID）
   - 返回：操作结果

## 页面数据结构

### 账户列表
- list: 账户数组
  - id: 账户ID
  - name: 账户名称
  - money: 账户余额
  - exemptMoney: 豁免金额
  - card: 卡号
  - note: 备注

### 状态
- loading: 加载状态
- finished: 是否加载完成
- error: 是否加载错误

## 主要交互逻辑

### 账户列表
- 列表展示所有账户
- 显示账户名称
- 点击查看详情

### 账户详情
- 弹出详情面板
- 显示：
  - 账户余额
  - 豁免金额及说明
  - 卡号
  - 备注
- 空值显示提示文字

### 编辑账户
- 点击"编辑账号"
- 跳转到账户编辑页面
- 传递账户ID

### 停用账户
- 点击"停用账号"
- 弹出确认对话框
- 说明：
  - 停用后无法记账
  - 数据不会删除
- 确认后调用接口

### 新增账户
- 点击右上角"添加账号"
- 跳转到账户新增页面

### 错误处理
- 加载失败显示错误提示
- 点击重新加载

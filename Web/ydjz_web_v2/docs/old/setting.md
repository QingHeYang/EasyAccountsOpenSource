# 设置页面

## 页面功能描述
应用设置入口页面，提供各项管理功能和应用信息。

## 调用的 API 接口列表

1. **GET** `/home/getVersion`
   - 用途：获取应用版本信息
   - 返回：版本号

## 页面数据结构

### 版本信息
- versions: 版本对象
  - release: 发行版本号

## 主要交互逻辑

### 功能入口
- 收支管理：跳转到操作管理页面
- 账户管理：跳转到账户列表页面
- 分类管理：跳转到分类列表页面
- 快记模板：跳转到模板管理页面

### 关于信息
- 点击"关于"
- 弹出对话框显示：
  - 应用Logo
  - 应用名称：EasyAccounts
  - 应用标语：认真生活，好好记账
  - 发行版本号
  - 开发者信息：
    - GitHub头像
    - 开发者名称：QingHeYang
    - GitHub仓库链接

### 退出登录
- 点击"退出登录"
- 弹出确认对话框
- 确认后清除token
- 跳转到登录页面

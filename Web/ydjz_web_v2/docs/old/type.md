# 分类管理页面

## 页面功能描述
查看和管理收支分类，支持一级和二级分类，可编辑和归档分类。

## 调用的 API 接口列表

1. **GET** `/type/getType`
   - 用途：获取所有启用的分类
   - 返回：分类树形结构

## 页面数据结构

### 分类列表
- list: 分类数组
  - id: 分类ID
  - tname: 分类名称
  - action: 关联的操作
    - hname: 操作名称
    - handle: 操作类型
    - style: 标签样式
  - childrenTypes: 子分类数组（结构同上）

### 状态
- activeNames: 展开的折叠项ID数组

## 主要交互逻辑

### 分类展示
- 折叠面板展示一级分类
- 点击展开查看二级分类
- 一级分类显示关联操作标签
- 二级分类也显示关联操作标签

### 编辑分类
- 点击"编辑一级分类"编辑父分类
- 点击二级分类编辑子分类
- 跳转到分类编辑页面
- 传递分类ID

### 新增分类
- 点击右上角"添加"
- 跳转到分类新增页面

### 管理归档
- 点击"管理归档"
- 跳转到归档分类页面
- 查看和恢复已归档的分类

### 操作标签
- 标签颜色：
  - 成功（绿色）：收入类
  - 危险（红色）：支出类
  - 主要（蓝色）：转账类

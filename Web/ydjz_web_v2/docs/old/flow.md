# 明细页面（流水列表）

## 页面功能描述
按月展示所有账单流水，支持筛选、排序、删除、收藏和生成报表。

## 调用的 API 接口列表

1. **GET** `/flow/getFlowListMain/{handle}/{order}/{month}`
   - 用途：获取指定月份的流水列表
   - 参数：
     - handle: 收支类型（0收入/1支出/2转账/3全部）
     - order: 排序方式（0按时间/1按金额）
     - month: 月份（YYYY-MM）
   - 返回：流水列表及统计数据

2. **DELETE** `/flow/deleteFlow/{flowId}`
   - 用途：删除指定流水
   - 参数：flowId（流水ID）

3. **PUT** `/flow/collectFlow/{flowId}/{status}`
   - 用途：收藏或取消收藏流水
   - 参数：
     - flowId: 流水ID
     - status: 收藏状态（0取消/1收藏）

4. **GET** `/flow/makeExcel/{month}`
   - 用途：生成月度Excel报表
   - 参数：month（月份）
   - 返回：报表生成结果

## 页面数据结构

### 筛选条件
- handle: 收支类型（全部/流入/流出/内部转账）
- order: 排序方式（按时间/按金额）
- chooseMonth: 选择的月份

### 统计数据
- totalIn: 当月总收入
- totalOut: 当月总支出
- totalEarn: 当月结余

### 流水列表
- flows: 流水数组
  - id: 流水ID
  - fdate: 日期
  - tname: 分类名称
  - aname: 账户名称
  - money: 金额
  - hname: 收支类型名称
  - note: 备注
  - collect: 是否收藏
  - exempt: 是否不计入总金额
  - hasImages: 是否有图片
  - from: 来源（如：ai）

## 主要交互逻辑

### 月份切换
- 点击月份按钮弹出日期选择器
- 左右按钮切换上月/下月
- 限制不能超过当前月份

### 筛选和排序
- 下拉菜单选择收支类型
- 下拉菜单选择排序方式
- 选择后自动刷新数据

### 流水操作
- 点击流水项：跳转到编辑页面
- 左滑显示备注内容
- 右滑显示操作按钮：
  - 收藏/取消收藏
  - 删除（需确认）

### 报表生成
- 点击"生成报表"按钮
- 确认后调用接口生成Excel
- 显示生成结果日志

### 浮动按钮
- 右下角"+"按钮
- 点击跳转到新增流水页面
- 支持拖拽调整位置

### 标签显示
- 收入/支出/转账不同颜色标签
- 图片标识：绿色"图"标签
- AI来源标识：渐变色"AI"标签
- 豁免金额标识：灰色标签

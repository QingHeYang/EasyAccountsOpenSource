# ydjz_web 项目业务逻辑文档

本目录包含 ydjz_web 项目所有页面的业务逻辑文档。

## 文档列表

### 核心功能页面

1. **[dashboard.md](dashboard.md)** - 总览页面（首页）
   - 显示资产总览、年度收支、月度明细
   - 账户详情查看

2. **[flow.md](flow.md)** - 明细页面（流水列表）
   - 按月展示流水明细
   - 支持筛选、排序、删除、收藏
   - 生成月度报表

3. **[flow-add.md](flow-add.md)** - 账单新增/编辑页面
   - 新增或编辑账单
   - 图片上传功能
   - 快记模板
   - 追加分账单

4. **[screen.md](screen.md)** - 筛选页面
   - 多维度高级筛选
   - 分类明细查看
   - 生成Excel报表

### 分析统计页面

5. **[analysis.md](analysis.md)** - 财务分析页面
   - 同比和环比分析
   - 生成财务分析报表

6. **[analysis-v2.md](analysis-v2.md)** - 分类统计页面（V2版本）
   - 按分类统计收支
   - 图表可视化展示

7. **[analysis-type.md](analysis-type.md)** - 单项分类统计页面
   - 单个分类详细统计
   - 按年份和月份展示

### AI功能页面

8. **[ai-plus.md](ai-plus.md)** - AI+ 智能助手页面
   - AI实时对话
   - 思考过程展示
   - 工具调用功能

### 设置管理页面

9. **[setting.md](setting.md)** - 设置页面
   - 功能入口导航
   - 应用信息展示
   - 退出登录

10. **[account.md](account.md)** - 账户管理页面
    - 账户列表查看
    - 账户新增、编辑、停用

11. **[action.md](action.md)** - 操作管理页面
    - 收支操作类型管理

12. **[type.md](type.md)** - 分类管理页面
    - 一级和二级分类管理
    - 分类归档功能

### 其他页面

13. **[login-register.md](login-register.md)** - 登录注册页面
    - 用户登录和注册
    - 密码加密和token认证

14. **[verify.md](verify.md)** - 验证码绑定页面
    - 二维码展示
    - 验证码绑定

    - 路由不存在时的提示页面

## 文档说明

每个文档包含以下内容：

1. **页面功能描述** - 页面的主要功能和用途
2. **调用的 API 接口列表** - 页面使用的所有后端接口，包括：
   - 接口路径和方法
   - 参数说明
   - 返回数据说明
3. **页面数据结构** - 页面中使用的主要数据对象
4. **主要交互逻辑** - 页面的核心业务逻辑和用户交互流程

## 技术栈

- **前端框架**: Vue 3
- **UI组件库**: Vant 4
- **HTTP客户端**: Axios
- **图表库**: ApexCharts
- **Markdown渲染**: markdown-it
- **加密**: crypto-js (MD5)
- **WebSocket**: 原生 WebSocket API

## 项目特点

1. **移动端优先**: 使用 Vant UI 组件库，专为移动端设计
2. **记账核心功能**: 完整的流水记录、分类统计、报表导出
3. **AI 集成**: 内置 AI 助手功能，支持智能对话
4. **图片支持**: 账单支持图片上传和压缩
5. **快记模板**: 提供模板功能快速记账
6. **数据分析**: 多维度的数据统计和可视化
7. **高级筛选**: 支持按多个条件组合筛选

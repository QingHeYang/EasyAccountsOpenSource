# 分类统计页面（V2版本）

## 页面功能描述
按分类统计收入和支出，支持图表展示，可查看单项分类详情。

## 调用的 API 接口列表

1. **POST** `/analysis/v2/getAnalysisTypeList`
   - 用途：获取分类统计数据
   - 参数：
     - start: 开始日期
     - end: 结束日期
     - combineSubType: 是否合并子分类
     - showDisableAnalysisType: 是否显示全部分类
   - 返回：收入/支出分类统计数据

## 页面数据结构

### 筛选条件
- startDate/endDate: 日期范围
- fastChoose: 快速选择（当月/上月/近3月/近6月/近1年/当年/上年/自定义）
- modelChoose: 模式选择
  - 合并子分类
  - 显示全部分类

### 统计数据
- totalIn: 总收入
- totalOut: 总支出
- showInTypeList: 显示的收入分类列表
- showOutTypeList: 显示的支出分类列表
- allInTypeList: 所有收入分类列表
- allOutTypeList: 所有支出分类列表

### 分类数据项
- name: 分类名称
- money: 金额
- percent: 占比百分比

## 主要交互逻辑

### 标签页切换
- 收入和支出两个标签页
- 切换时更改主题颜色
- 重新渲染数据和图表

### 时间筛选
- 快速选择常用时间范围
- 自定义选择开始和结束日期
- 日期选择器限制合理范围

### 参数设置
- 合并子分类：将子分类合并到父分类
- 显示全部分类：包括停用的分类

### 图表展示
- 使用 TreeMap 图表展示分类占比
- 点击"查看图表"弹出图表窗口
- 图表配色根据收入/支出自动调整

### 分类明细
- 列表展示各分类金额和占比
- 点击分类跳转到单项分类统计页面

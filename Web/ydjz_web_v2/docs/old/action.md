# 操作管理页面

## 页面功能描述
查看和管理所有收支操作类型，如流入、流出、内部转账等。

## 调用的 API 接口列表

1. **GET** `/action/getAction`
   - 用途：获取所有操作类型
   - 返回：操作列表

## 页面数据结构

### 操作列表
- allActions: 操作数组
  - id: 操作ID
  - hname: 操作名称
  - handle: 操作类型（0增加/1减少/2不变）
  - exempt: 是否不计入总金额
  - handleText: 操作说明
  - style: 标签样式
  - value: 豁免标识文字

## 主要交互逻辑

### 操作列表
- 列表展示所有操作
- 显示操作名称
- 显示操作类型标签：
  - 成功（绿色）：账户金额增加
  - 危险（红色）：账户金额减少
  - 主要（蓝色）：账户金额不变
- 显示豁免标识（灰色）：不计入总金额

### 操作详情
- 点击操作项
- 跳转到操作编辑页面
- 传递操作ID

### 新增操作
- 点击右上角"添加操作"
- 跳转到操作新增页面

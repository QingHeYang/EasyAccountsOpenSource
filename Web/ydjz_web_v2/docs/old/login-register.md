# 登录注册页面

## 页面功能描述
用户登录和注册功能，支持密码加密和token认证。

## 调用的 API 接口列表

1. **POST** `/auth/login`
   - 用途：用户登录
   - 参数：
     - username: 用户名
     - password: 密码（MD5加密）
   - 返回：token

2. **POST** `/auth/register`
   - 用途：用户注册
   - 参数：
     - username: 用户名
     - password: 密码（MD5加密）
   - 返回：token

## 页面数据结构

### 表单数据
- username: 用户名
- password: 密码
- mode: 模式（1登录/0注册）

## 主要交互逻辑

### 表单验证
- 用户名长度：3-10位
- 密码长度：6-15位
- 不允许包含空格
- 验证失败清空输入框

### 登录流程
1. 输入用户名和密码
2. 点击登录按钮
3. 密码MD5加密后提交
4. 成功后保存token到localStorage
5. 跳转到首页或重定向地址

### 注册流程
1. 输入用户名和密码
2. 点击注册按钮
3. 密码MD5加密后提交
4. 成功后保存token到localStorage
5. 跳转到首页或重定向地址

### 忘记密码
- 点击"忘记密码"
- 显示重置密码说明：
  - 删除服务器secret.key文件
  - 刷新页面重新注册
  - 数据不会丢失

### 1. 负债账户与不计入收支的双向限制逻辑

#### 1.1 业务规则

负债账户不支持"不计入金额"功能，因此需要双向限制：

**账户 → 收支 限制（选了负债账户后）：**

| 负债账户位置 | 禁用的收支类型 |
|-------------|--------------|
| 源账户 | 普通不计入 + 转出不计入 + 两边不计入 |
| 目标账户 | 转入不计入 + 两边不计入 |

**收支 → 账户 限制（选了不计入收支后）：**

| 收支类型 | 禁用的账户 |
|---------|----------|
| 普通不计入（收入/支出） | 所有负债账户 |
| 转出不计入 | 负债账户不能作为源账户 |
| 转入不计入 | 负债账户不能作为目标账户 |
| 两边不计入 | 负债账户不能作为源/目标账户 |

#### 1.2 核心函数实现

```typescript
/**
 * 判断账户是否应该被禁用（根据已选收支类型）
 */
function isAccountDisabled(account: Account, panelType: 1 | 2): boolean {
  // 如果账户不是负债，不禁用
  if (account.accountType !== AccountType.LIABILITY) return false

  // 如果没选收支，或者收支不是"不计入"类型，不禁用
  if (!selectedAction.value?.exempt) return false

  // 普通不计入收支（非转账）：禁用所有负债账户
  if (selectedAction.value.handle !== ActionHandle.TRANSFER) {
    return true
  }

  // 内部转账的不计入，根据 exemptMode 判断
  const mode = selectedAction.value.exemptMode ?? ExemptMode.NONE

  if (panelType === 1) {
    // 源账户面板：禁用负债如果是转出不计入或两边不计入
    return mode === ExemptMode.FROM_EXEMPT || mode === ExemptMode.BOTH_EXEMPT
  } else {
    // 目标账户面板：禁用负债如果是转入不计入或两边不计入
    return mode === ExemptMode.TO_EXEMPT || mode === ExemptMode.BOTH_EXEMPT
  }
}

/**
 * 判断收支是否应该被禁用（根据已选账户）
 */
function isActionDisabled(action: Action): boolean {
  // 如果收支不是"不计入"类型，不禁用
  if (!action.exempt) return false

  // 检查源账户和目标账户是否为负债
  const sourceIsLiability = selectedAccount.value?.accountType === AccountType.LIABILITY
  const targetIsLiability = selectedAccountTo.value?.accountType === AccountType.LIABILITY

  // 如果都不是负债，不禁用
  if (!sourceIsLiability && !targetIsLiability) return false

  // 普通不计入收支（非转账）：只要源账户是负债就禁用
  if (action.handle !== ActionHandle.TRANSFER) {
    return sourceIsLiability
  }

  // 内部转账的不计入
  const mode = action.exemptMode ?? ExemptMode.NONE

  if (sourceIsLiability) {
    if (mode === ExemptMode.FROM_EXEMPT || mode === ExemptMode.BOTH_EXEMPT) {
      return true
    }
  }

  if (targetIsLiability) {
    if (mode === ExemptMode.TO_EXEMPT || mode === ExemptMode.BOTH_EXEMPT) {
      return true
    }
  }

  return false
}
```

## 技术要点

### 1. 双向限制的响应式

由于 `isAccountDisabled` 和 `isActionDisabled` 是普通函数而非计算属性，每次渲染时都会重新计算。这确保了：

- 选择账户后，收支列表立即更新禁用状态
- 选择收支后，账户列表立即更新禁用状态
- 更改选择后，之前的禁用状态自动解除

### 2. 删除旧的过滤逻辑

移除了 `transferableAccounts` 计算属性，不再根据账户的 `exemptMoney` 过滤账户列表。现在所有账户都会显示，只有负债账户在特定收支类型下会被禁用（但仍然可见）。

### 3. 禁用原因提示

- 桌面端：使用 `el-tooltip` 悬停显示
- 移动端：直接在列表项中显示文字

## 技术要点

### 禁用功能设计

1. **API 分离**：`getAll()` 返回启用的收支（用于记账页面），`getAllWithDisabled()` 返回全部（用于管理页面）
2. **仅编辑可禁用**：新增收支时不显示禁用开关，只有编辑已有收支时才可禁用
3. **警告提示**：禁用收支会影响快记模板，需要明确告知用户

### 13. Version API 更新（v2.6.0）

#### 13.1 接口变更

新增字段：
- `versions.versionCode`：当前版本码
- `update`：更新信息（有新版本时返回，无更新时为 null）

#### 13.2 类型定义更新（home.ts）

```typescript
/** 版本信息 */
export interface VersionInfo {
  release: string
  versionCode: number  // 新增
  fontBranch: string
  backendBranch: string
  mysqlBranch: string
  agentBranch: string
  webhookBranch: string
}

/** 更新信息 */
export interface UpdateInfo {
  version: string
  versionCode: number
  releaseDate: string
  changelog: string  // Markdown 格式
}

/** 系统配置 */
export interface SystemConfig {
  versions: VersionInfo
  auth: AuthConfig
  backup: BackupConfig
  update: UpdateInfo | null  // 新增
}
```

## 技术要点

### Markdown 渲染

使用项目已有的 `markdown-it` 库渲染 changelog：

```typescript
import MarkdownIt from 'markdown-it'
const md = new MarkdownIt()

const changelogHtml = computed(() => {
  if (!updateInfo.value?.changelog) return ''
  return md.render(updateInfo.value.changelog)
})
```

模板中使用 `v-html` 渲染：
```vue
<div class="changelog-content markdown-body" v-html="changelogHtml"></div>
```

### 更新提示设计

1. **非侵入式**：仅在设置页面"关于"处显示红点，不打断用户操作
2. **层级展示**：关于按钮红点 → 关于弹窗横幅 → 更新详情弹窗
3. **信息完整**：版本号、版本码、发布日期、更新内容、更新指南链接

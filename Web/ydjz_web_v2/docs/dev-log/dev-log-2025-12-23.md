### 2. 明细页面增强 (Flow.vue)

#### 日历组件

新增日历视图，可点击日期快速定位到对应流水：

```typescript
// 有记账的日期集合
const datesWithRecords = computed(() => {
  const dates = new Set<string>()
  if (flowData.value?.flows) {
    for (const flow of flowData.value.flows) {
      dates.add(flow.fdate)
    }
  }
  return dates
})

// 点击日历日期，滚动到该日流水
function onCalendarDateClick(date: Date) {
  const dateStr = formatDate(date)
  const groupEl = document.querySelector(`[data-date="${dateStr}"]`)
  if (groupEl) {
    groupEl.scrollIntoView({ behavior: 'smooth', block: 'start' })
  }
}
```

#### 收藏按钮优化

已收藏的项目星星始终显示，未收藏的 hover 时才显示：

```css
/* 已收藏的星星始终显示 */
.flow-actions .always-show {
  opacity: 1;
}

/* hover 才显示的按钮 */
.flow-actions .hover-show {
  opacity: 0;
  transition: opacity 0.2s;
}

.flow-item:hover .flow-actions .hover-show {
  opacity: 1;
}
```

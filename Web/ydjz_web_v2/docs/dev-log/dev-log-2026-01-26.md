## 今日开发内容

### 1. Nginx 移动端检测修复

#### 1.1 问题描述

手机访问 IP:port 时，第一次显示桌面端，刷新后才显示移动端。

#### 1.2 原因分析

```nginx
# 原配置
location / {
    root /usr/share/nginx/html;
    try_files $uri $uri/ /$entry_file;
}
```

问题在于 `try_files $uri $uri/`：
- 访问根路径 `/` 时，`$uri/` 匹配目录
- nginx 默认 index 行为会自动查找 `index.html`
- 导致直接返回 `index.html`，未按设备类型选择入口文件

#### 1.3 解决方案

```nginx
# 修复后
location / {
    root /usr/share/nginx/html;
    try_files $uri /$entry_file;
}
```

移除 `$uri/`，避免触发 nginx 默认 index 行为。

### 2. 备份恢复功能优化

#### 2.1 文件选择框修复

**问题：** 点击上传区域无法弹出文件选择框

**原因：** 使用 `document.getElementById()` 在 Vue 组件中不可靠

**修复：** 改用 Vue 的 `ref` 引用

```typescript
// 修复前
@click="() => document.getElementById('backup-file-input')?.click()"

// 修复后
const fileInputRef = ref<HTMLInputElement | null>(null)

function triggerFileSelect() {
  fileInputRef.value?.click()
}
```

```vue
<input ref="fileInputRef" type="file" ... />
<div @click="triggerFileSelect">...</div>
```

### 3. 公告功能

#### 3.1 API 接口

**新增类型** (`src/shared/api/home.ts`):

```typescript
/** 公告信息 */
export interface Notice {
  /** 公告唯一标识 */
  id: number
  /** 公告标题 */
  title: string
  /** 公告内容 */
  content: string
  /** 发布日期 (yyyy-MM-dd) */
  date: string
  /** 跳转链接，空则无链接 */
  url: string
  /** 过期日期，空则永不过期 */
  expire: string
}
```

**新增 API**:

```typescript
/** 获取公告列表（自动过滤已过期公告） */
getNotices() {
```

#### 3.4 已读状态管理

```typescript
const NOTICE_READ_KEY = 'easyaccounts_read_notices'

// 获取已读 ID 列表
function getReadNoticeIds(): number[] {
  const stored = localStorage.getItem(NOTICE_READ_KEY)
  return stored ? JSON.parse(stored) : []
}

// 保存已读 ID
function saveReadNoticeIds(ids: number[]) {
  localStorage.setItem(NOTICE_READ_KEY, JSON.stringify(ids))
}

// 未读数量
const unreadCount = computed(() => {
  const readIds = getReadNoticeIds()
  return notices.value.filter(n => !readIds.includes(n.id)).length
})
```

### 1. Vue 组件 ref 暴露

使用 `defineExpose` 暴露组件内部状态给父组件：

```typescript
// 子组件
defineExpose({
  hasUnread,
  unreadCount,
  loadNotices,
})

// 父组件
const noticeDrawerRef = ref<InstanceType<typeof NoticeDrawer> | null>(null)
const hasUnreadNotice = computed(() => noticeDrawerRef.value?.hasUnread ?? false)
```

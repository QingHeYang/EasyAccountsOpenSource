## 今日开发内容

### 1. 移动端 4 数据页面 loading + 错误占位

#### 起源
用户：移动端切年度 / 切月份没有 loading 反馈，网络错误时显示前一次的数据让用户疑惑。

#### 4 个页面统一改造
| 页面 | 文件 |
|---|---|
| Board（总览） | `mobile/views/Board.vue` |
| Flow（明细） | `mobile/views/Flow.vue` |
| Analysis（统计主页） | `mobile/views/Analysis.vue` |
| AnalysisType（分类详情） | `mobile/views/analysis/AnalysisType.vue` |

每个页面的 fetch 函数都做了同样改造：
1. 进入时 `showLoadingToast({ message: '加载中...', forbidClick: true, duration: 0 })`
2. **success 路径**：try 内 `closeToast()` 关 loading toast
3. **error 路径**：catch 内**不调** closeToast（让全局 onError 弹的 fail toast 自然显示 2s）+ 清空数据 + `loadFailed = true`
4. finally 仅 `loading = false`
5. 模板 van-empty 改成动态：`:image="loadFailed ? 'network' : 'default'"` + `:description="loadFailed ? '加载失败...' : '暂无...'"`

#### 关键 bug 修复
**closeToast 把 fail toast 一起关掉了**：之前几个页面的 catch 内调 closeToast()，这会把全局 onError 弹的 showFailToast(msg) 秒关，用户看不到错误信息。修复：catch 不再 closeToast。

#### 经验固化
> **Vant 的 Toast 单实例**：`showLoadingToast` / `showFailToast` 共享同一个 toast 实例，后调覆盖前调。如果业务在 catch 里 closeToast 会把全局错误 toast 也一起关掉。**正确姿势**：success 才关 loading，error 让全局接管。

### 7. AnalysisType chooseHandle 修复

#### Bug
用户："我有一个分类，既有收入也有支出，我指的是一级。但是 chooseHandle 到传的是 1"。

#### 原因
`onMonthItemClick` 的逻辑 `chooseHandle = hasExpense ? 1 : 0`，只要月份有支出就只看支出，把收入流水过滤掉了。父级聚合下一级分类可能挂着收入子类和支出子类，用户期望同时显示两种流水。

#### 修复
```ts
let chooseHandle: number
if (hasIncome && hasExpense) {
  chooseHandle = 3  // 全部
} else if (hasExpense) {
  chooseHandle = 1
} else {
  chooseHandle = 0
}
```

—— `screen.ts` 的 `chooseHandle: 3 = 全部`（已确认）。

## 遇到的坑 / 注意事项

### 1. Vant 单例 toast 时序冲突
`closeToast()` 在 catch 里会把全局 `onError` 弹的 fail toast 秒关。**正确做法**：success 才关 loading toast，error 让全局接管。

### 2. esbuild 不支持 object 字面量方法重载
（part3 留过）—— interface 提供重载签名 + object 实现用宽签名 `any`。

### 3. canvas-confetti 默认 zIndex 不够
默认 z-index 不会自动盖过 el-dialog（默认 ~2000）/ van-popup（默认 ~2000）。**修复**：`confetti({ ... zIndex: 99999 })`。

### 4. v-html 渲染需要爽快地相信内容来源
公告内容来自后端管理员维护的接口，可信。配 `markdown-it { html: false }` 防 raw HTML XSS，不用再上 DOMPurify。

### 5. `:has()` 选择器现代浏览器才支持
（part3 留过）—— 这次 StatTypePicker 用 `.stp-group:has(.stp-parent.active)` 实现"整张群组卡变色"，Chrome 105+ / Safari 15.4+ / iOS 16.4+ 才支持。EasyAccounts 浏览器目标足够新，OK。

### 6. ScrollHeight measure 时机
NoticeCard / TypePicker 的"内容超过 N 行才显示展开按钮"判定 —— 用 `onMounted` + `watch(contentHtml)` + `nextTick(measure)` 测 `contentEl.scrollHeight`，对 markdown 渲染后高度敏感。

### 7. emoji 渲染需要变体选择符
`☀️`（U+2600 + U+FE0F）跟 `☀`（U+2600）显示不同，加 `️` 才能保证彩色渲染。

### 8. text-overflow + direction: rtl 末尾保留技巧
长分类路径"餐饮/外卖/午餐"在窄空间下，`direction: rtl + text-align: left` 可以让省略发生在前面，保留末尾"午餐"。

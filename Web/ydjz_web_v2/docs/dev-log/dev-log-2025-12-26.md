## 技术要点

### 抽屉层级体系

```
页面 → 分类选择抽屉 → 流水列表抽屉 → FlowEditor 抽屉
```

每层抽屉独立管理，点击流水时 FlowEditor 以更高层级覆盖显示。

### 日期选择器双向绑定

使用 `@update:model-value` 替代 `v-model` 实现更精细的控制：

```vue
<el-date-picker
  :model-value="localStartDate"
  @update:model-value="onStartDateChange"
/>
```

### 金额格式化

```typescript
function formatAmount(amount: string, expanded: boolean): string {

  if (expanded) return num.toFixed(2)        // 完整显示
  if (Math.abs(num) >= 10000) return (num / 10000).toFixed(2) + '万'
  return num.toFixed(2)
}
```

### 2. FlowEditor 图片拖拽/粘贴功能

#### 2.1 功能说明

| 功能 | 说明 |
|------|------|
| 拖拽图片 | 将图片文件拖到上传区域即可添加 |
| 粘贴图片 | 在备注框按 Ctrl+V 粘贴剪贴板图片 |
| 视觉反馈 | 拖拽时显示蓝色边框和提示遮罩 |
| 格式支持 | PNG、JPG、WebP |

#### 2.2 实现方式

```typescript
// 拖拽状态
const isDragOver = ref(false)
const ALLOWED_IMAGE_TYPES = ['image/png', 'image/jpeg', 'image/jpg', 'image/webp']

// 拖拽事件处理
function handleDragEnter(e: DragEvent) {
  e.preventDefault()
  isDragOver.value = true
}

function handleDragLeave(e: DragEvent) {
  e.preventDefault()
  const rect = (e.currentTarget as HTMLElement).getBoundingClientRect()
  if (
    e.clientX < rect.left ||
    e.clientX > rect.right ||
    e.clientY < rect.top ||
    e.clientY > rect.bottom
  ) {
    isDragOver.value = false
  }
}

async function handleDrop(e: DragEvent) {
  e.preventDefault()
  isDragOver.value = false
  const files = e.dataTransfer?.files
  if (files) {
    await processImageFiles(Array.from(files))
  }
}

// 粘贴图片处理
async function handlePaste(e: ClipboardEvent) {
  const items = e.clipboardData?.items
  if (!items) return

  const imageFiles: File[] = []
  for (const item of items) {
    if (item.type.startsWith('image/')) {
      const file = item.getAsFile()
      if (file) imageFiles.push(file)
    }
  }

  if (imageFiles.length > 0) {
    e.preventDefault()
    await processImageFiles(imageFiles)
  }
}
```

```vue
<!-- 图片上传区域添加拖拽事件 -->
<div
  class="upload-area"
  :class="{ 'drag-over': isDragOver }"
  @dragenter="handleDragEnter"
  @dragleave="handleDragLeave"
  @dragover="handleDragOver"
  @drop="handleDrop"

  <!-- 拖拽提示遮罩 -->

  </div>

</div>

<!-- 备注框添加粘贴事件 -->
<el-input @paste="handlePaste" />
```

### 3. AIDrawer 附件交互优化

#### 3.1 问题：删除按钮显示不全

原因：`.attachment-item` 设置了 `overflow: hidden`，但删除按钮位置在外部 `top: -4px`。

#### 3.2 修复方案

参照 FlowEditor 样式：

| 原样式 | 新样式 |
|--------|--------|
| `overflow: hidden` | 移除 |
| 删除按钮 `top: -4px` | 改为 `top: 2px`（内部） |
| 始终显示 | hover 时才显示 |
| 红色背景 | 半透明黑色，hover 变红 |

```css
.attachment-item {
  position: relative;
  width: 56px;
  height: 56px;
  border-radius: 8px;
  /* 移除 overflow: hidden */
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
}

.attachment-remove {
  position: absolute;
  top: 2px;
  right: 2px;
  width: 18px;
```

## 技术要点

### 拖拽事件处理注意事项

1. **dragenter/dragleave 冒泡问题**：进入子元素时也会触发，需要通过坐标判断是否真正离开区域
2. **dragover 必须 preventDefault**：否则 drop 事件不会触发
3. **粘贴事件**：只在包含图片时阻止默认行为，否则允许正常粘贴文本

### overflow: hidden 与绝对定位

当子元素使用 `position: absolute` 且定位在父元素外部时，父元素的 `overflow: hidden` 会裁剪子元素。解决方案：
- 移除 `overflow: hidden`
- 或将子元素定位改为内部

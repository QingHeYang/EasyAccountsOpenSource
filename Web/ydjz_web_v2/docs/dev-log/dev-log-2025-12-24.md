### 1. FlowEditor 账单编辑器组件（新增）

新增 PC 端账单添加/编辑抽屉组件。

#### 文件位置

```
src/desktop/components/flow/FlowEditor.vue
```

#### 组件功能

- 双模式支持：新增 / 编辑（根据 flowId 判断）
- 金额输入区：渐变背景，颜色随收支类型变化
- 收支类型切换：胶囊按钮
- 账户/分类/日期选择器
- 快记模板：标签筛选 + 一键填充
- 图片上传：压缩上传，最多3张
- 暗色模式适配

#### 使用方式

```vue
<FlowEditor
  v-model:visible="showEditor"
  :flow-id="editFlowId"
  @success="fetchFlows"
/>
```

### 2. Flow.vue 明细页面优化

#### 接入 FlowEditor 组件

```typescript
import FlowEditor from '@desktop/components/flow/FlowEditor.vue'

const showEditor = ref(false)
const editFlowId = ref<number | null>(null)

function toAddFlow() {
  editFlowId.value = null
  showEditor.value = true
}

function toFlowDetail(flow: Flow) {
  editFlowId.value = flow.id
  showEditor.value = true
}
```

#### 滚动优化

移除固定高度限制，改为页面整体滚动：

```css
/* 修改前 */
.flow-page {
  height: calc(100vh - 80px);
  overflow: hidden;
}

/* 修改后 */
.flow-page {
  min-height: calc(100vh - 80px);
}
```

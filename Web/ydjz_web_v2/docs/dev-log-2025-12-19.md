# 开发日志 - 2025年12月19日

## 项目概述

**项目名称**: ydjz_web_v2 (EasyAccounts V2)
**项目类型**: 个人记账应用前端重构
**技术栈**: Vue 3 + TypeScript + Vite + Pinia

## 今日开发内容

### 1. 移动端核心页面

#### 1.1 总览页 (Board.vue)
- 年度财务总览，支持年份切换

- 账户列表：支持列表/网格两种布局模式
- 月度明细：收入/支出/结余统计
- **滚动交互**: 资产卡片滚出视图时，header 显示"总资产 ¥xxx"

#### 1.2 明细页 (Flow.vue)
- 按月查看流水记录
- **月份选择器**: Popover 双列滚轮（年份+月份），带确定/取消按钮
- **滚动交互**: 月份卡片滚出视图时，header 显示当前月份
- **筛选功能**: 可折叠的筛选栏，支持收支类型和账户筛选
- **长按操作**: FlowItem 长按弹出 ActionSheet，支持收藏/删除
- **Excel 导出**: 调用后端 API 生成报表

#### 1.3 设置页 (Setting.vue)
- 数据管理入口：收支、账户、分类、快记模板
- 外观设置：主题模式切换（浅色/深色/跟随系统）
- 关于弹窗：精心设计的品牌展示页

#### 1.4 登录页 (Auth.vue)
- 支持登录/注册模式切换
- 毛玻璃卡片效果
- 背景装饰：红绿银行卡 + 蓝色三条线

### 2. 设置子页面

## 技术特性

### 1. 主题系统
- CSS 变量定义主题色
- 支持浅色/深色/跟随系统
- Vant ConfigProvider 集成

### 2. 滚动状态管理
- 使用 `onActivated` / `onDeactivated` 管理滚动监听
- 解决 keep-alive 导致的页面共享滚动状态问题

### 3. 毛玻璃效果
- `backdrop-filter: blur()` 实现
- 需要 `-webkit-backdrop-filter` 兼容 Safari

### 4. 长按交互
- `touchstart` + `setTimeout` 实现
- `touchmove` / `touchend` 取消长按
- 配合 `isPressing` 状态阻止点击事件

### 5. 月份选择器
- Popover + 自定义双列滚轮
- 打开时锁定页面滚动 (`document.body.style.overflow = 'hidden'`)
- 隐藏滚动条 (`scrollbar-width: none`)

## 遇到的坑与解决方案

### 1. Vant Dialog 样式无法覆盖
**问题**: 使用 `showDialog()` 函数调用的对话框，样式无法通过 scoped CSS 修改
**原因**: 函数式调用的组件挂载到 body 根节点
**解决**: 使用 CSS 变量 `--van-dialog-*` 或全局样式选择器

### 2. 页面切换后滚动状态错误
**问题**: Board 和 Flow 页面切换后，header 显示状态不正确
**原因**: keep-alive 保留组件状态，但共享 window 滚动位置
**解决**: 使用 `onActivated` 重新计算滚动状态，`onDeactivated` 移除监听

### 3. 月份选择器滚动穿透
**问题**: 打开选择器后，背景页面仍可滚动
**解决**: 打开时设置 `document.body.style.overflow = 'hidden'`

### 4. FlowItem 备注字段名称错误
**问题**: 备注不显示
**原因**: API 返回字段是 `note` 而非 `remark`
**解决**: 检查 API 类型定义，使用正确字段名

### 5. TypeScript 图片导入报错
**问题**: `import logo from '@shared/assets/logo.png'` 类型错误
**解决**: `vite/client` 类型已包含静态资源声明，确保 `env.d.ts` 有引用

## 关键代码片段

### 1. 滚动状态管理 (Board.vue)

```typescript
import { onActivated, onDeactivated } from 'vue'

// 滚动检测 - header 显示资产
const showAssetInHeader = ref(false)
const assetCardRef = ref<HTMLElement | null>(null)

function handleScroll() {
  if (assetCardRef.value) {
    const rect = assetCardRef.value.getBoundingClientRect()
    showAssetInHeader.value = rect.bottom < 60
  }
}

onActivated(() => {
  handleScroll()
  window.addEventListener('scroll', handleScroll, { passive: true })
})

onDeactivated(() => {
  window.removeEventListener('scroll', handleScroll)
})
```

### 2. 长按操作 (FlowItem.vue)

```typescript
let pressTimer: ReturnType<typeof setTimeout> | null = null
const isPressing = ref(false)
const showActionSheet = ref(false)

function onTouchStart() {
  isPressing.value = false
  pressTimer = setTimeout(() => {
    isPressing.value = true
    showActionSheet.value = true
  }, 500)
}

function onTouchEnd() {
  if (pressTimer) {
    clearTimeout(pressTimer)
    pressTimer = null
  }
}

function onClick() {
  if (isPressing.value) {
    isPressing.value = false
    return
  }
  emit('click', props.flow)
}
```

### 4. 主题 Store (theme.ts)

```typescript
export const useThemeStore = defineStore('theme', () => {
  const mode = ref<ThemeMode>('system')

  const effectiveTheme = computed(() => {
    if (mode.value === 'system') {
      return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'
    }
    return mode.value
  })

  function set(newMode: ThemeMode) {
    mode.value = newMode
    applyTheme(effectiveTheme.value)
  }

  return { mode, effectiveTheme, set }
})
```

### 1. AI+ 对话功能基础架构

#### 1.1 Chat 服务架构

#### 1.2 UnifiedMessage 统一消息结构

支持多种消息类型：用户消息、AI 回复、工具调用、子智能体。

```typescript
export type MessageRole = 'user' | 'assistant' | 'tool' | 'agent'
export type MessageType = 'text' | 'tool' | 'agent'
export type ToolStatus = 'pending' | 'success' | 'error'

export class UnifiedMessage {
  id: string
  role: MessageRole | ''
  messageType: MessageType | ''
  content: MessageContent      // 文本内容
  tool: ToolInfo              // 工具调用信息
  agent: AgentInfo            // 子智能体信息
  meta: MessageMeta           // 元数据
}
```

#### 1.3 ChatService WebSocket 管理

管理 WebSocket 连接、重连、心跳响应。

**连接配置：**
```typescript
const DEFAULT_CONFIG: ChatConfig = {
  userId: 'user_67ce21d6-a11c-4340-851b-7a8949906aa3',
  appId: 'easy-accounts-agent',
  useThinkLlm: false
}
```

**WebSocket URL（直连后端）：**
```
ws://www.lllama.cn:10676/ws/chat?user_id=xxx&agent_id=xxx
```

**消息发送格式：**
```json
{
  "conversation_id": "会话ID",
  "content": "用户消息"
}
```

**Composable 接口：**
```typescript
export function useChatService() {
  return {
    connectionState,    // 连接状态：disconnected | connecting | connected | error
    isStreaming,        // 是否正在流式输出
    connect,            // 连接 WebSocket
    disconnect,         // 断开连接
    sendMessage,        // 发送消息
    newConversation,    // 新建对话
  }
}
```

#### 1.4 MessageStore 消息存储

响应式消息管理，处理 WebSocket 消息并维护消息列表。

**支持的消息类型：**

| 类型 | 说明 |
|-----|------|
| `chunk` | 流式文本片段 |
| `segment` | 完整段落 |
| `tool_call` | 工具调用开始 |
| `tool_response` | 工具调用结果 |
| `start` | 子智能体启动 |
| `exit` | 对话结束 |
| `title` | 标题更新 |
| `error` | 错误消息 |

### 2. FlowList 月份选择器修复

修复月份选择器显示两个日期的问题。

**问题：** 之前使用透明覆盖层方案，导致显示两个日期

**解决方案：** 直接使用 el-date-picker，通过 CSS 变量覆盖样式

```vue
<el-date-picker
  v-model="pickerMonth"
  type="month"
  format="YYYY年M月"
  class="month-picker"
/>
```

```css
.month-selector :deep(.month-picker) {
  --el-date-editor-width: auto;
  --el-fill-color-blank: transparent;
}

.month-selector :deep(.month-picker .el-input__wrapper) {
  background: transparent !important;
  box-shadow: none !important;
}

.month-selector :deep(.month-picker .el-input__inner) {
  color: #fff !important;
  font-size: 18px;
  font-weight: 600;
}
```

**暗色模式适配：**
```css
html.dark .flow-list-page .month-picker {
  --el-fill-color-blank: transparent;
}
```

### 3. FlowEditor 不计入统计分类折叠

将"不计入统计"的 action 分离，折叠隐藏。

```typescript
const normalActions = computed(() => actions.value.filter(a => !a.exempt))
const exemptActions = computed(() => actions.value.filter(a => a.exempt))
const exemptActionsExpanded = ref(false)
```

```vue
<!-- 普通 action -->
<div class="action-tabs">
  <div v-for="action in normalActions" ...>
    {{ action.hname }}
  </div>
</div>

<!-- 不计入的 action（折叠区域） -->
<div v-if="exemptActions.length > 0" class="exempt-actions-section">
  <div class="exempt-toggle" @click="exemptActionsExpanded = !exemptActionsExpanded">
    <span>不计入统计</span>
    <el-icon :class="{ rotated: exemptActionsExpanded }"><ArrowDown /></el-icon>
  </div>
  <div v-show="exemptActionsExpanded" class="exempt-actions">
    ...
  </div>
</div>
```

### 5. TypeDetail 流水列表优化

优化分类详情页的流水列表显示。

**改进内容：**
- 使用 FlowItem 组件显示流水（与 FlowList 保持一致）
- 按日期分组显示
- 支持收藏/删除操作
- 月份点击智能判断（只有收入显示收入，只有支出显示支出）

```typescript
// 按日期分组
const groupedFlows = computed(() => {
  const groups: { date: string; dateLabel: string; flows: Flow[] }[] = []
  // ... 分组逻辑
  return groups
})

// 月份点击逻辑
function onMonthItemClick(year: number, month: MonthData) {
  const hasIncome = parseFloat(month.income) > 0
  const hasOutcome = parseFloat(month.outcome) > 0

  if (hasIncome && !hasOutcome) {
    onMonthClick(year, month.month, 0) // 收入
  } else {
    onMonthClick(year, month.month, 1) // 支出（默认）
  }
}
```

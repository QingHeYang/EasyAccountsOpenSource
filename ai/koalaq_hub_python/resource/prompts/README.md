# 提示词系统目录

本目录采用分层架构设计，将提示词按功能和职责组织成不同层次。

## 目录结构

```
prompts/
├── layers/          # 分层提示词片段
│   ├── base/       # 基础层：系统行为规范
│   ├── role/       # 角色层：身份和性格定义
│   ├── capability/ # 能力层：工具和技能描述
│   ├── context/    # 上下文层：历史和动态信息
│   └── task/       # 任务层：Agent专属指导
├── functions/      # 功能型提示词（独立使用）
└── agents/         # Agent专属完整配置
```

## 设计理念

1. **模块化**：每个片段独立，可单独测试和维护
2. **可组合**：通过组装器动态组合不同片段
3. **分层管理**：按职责分离，避免混乱
4. **灵活配置**：支持Agent级别的个性化定制

## 使用方式

提示词通过`PromptAssembler`组装器动态组合，根据Agent配置选择和组装不同的片段。

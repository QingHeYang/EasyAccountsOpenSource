# 输出格式规范模块

定义AI输出的格式规范，确保回复的结构清晰、易读。

## 文件说明

- `format_rules.prompt` - 标准格式规范
- `format_rules_mini.prompt` - 精简版格式规范
- `format_rules_technical.prompt` - 技术文档格式（可选）
- `format_rules_report.prompt` - 报告格式（可选）

## 内容范围

- Markdown使用规范
- 列表和表格格式
- 代码块标记
- 数据展示方式
- 语言规范（中/英文）

## 使用建议

大部分Agent使用标准版即可。特殊场景（如技术文档、数据报告）可创建专门的格式规范。

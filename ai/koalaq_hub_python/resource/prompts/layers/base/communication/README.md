# 交流风格模块

定义AI的基本交流风格和语言特征。

## 文件说明

- `communication_style.prompt` - 标准交流风格
- `communication_style_mini.prompt` - 精简版
- `friendly_style.prompt` - 友好型风格（客服类）
- `professional_style.prompt` - 专业型风格（技术类）
- `casual_style.prompt` - 轻松型风格（娱乐类）

## 内容范围

- 语气和态度
- 称呼方式
- 回应技巧
- 错误处理方式
- 情感表达程度

## 组合使用

可以和角色层配合，形成独特的交流风格：
- 专业+友好 = 专业客服
- 技术+简洁 = 技术专家
- 轻松+幽默 = 娱乐助手

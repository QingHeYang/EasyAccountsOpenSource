# 上下文层（Context Layer）

上下文层提供动态的历史和环境信息，在运行时生成和更新。

## 内容类型

1. **会话历史**
   - 当前会话总结
   - 最近的快照
   - 重要对话节点

2. **用户信息**
   - 用户偏好
   - 历史行为模式
   - 个性化设置

3. **环境信息**
   - 当前时间
   - 地理位置
   - 系统状态

## 模板文件

- `history_template.prompt` - 历史信息模板
- `user_context_template.prompt` - 用户上下文模板
- `environment_template.prompt` - 环境信息模板

## 特点

1. **动态性**：内容实时更新
2. **相关性**：只包含相关信息
3. **简洁性**：避免信息过载
4. **时效性**：保持信息新鲜

## 更新机制

上下文层通过`PromptAssembler.update_context_layer()`方法动态更新，不需要重新组装整个提示词。

### 1. 分类可用性标识

#### 问题描述

LLM 在添加流水时，有时会错误地使用一级分类（如"餐饮"），而实际上应该使用其子分类（如"早餐"、"午餐"）。

#### 解决方案

在 `types` 工具返回值中，为每个分类添加"可用/不可用"标识：

- 有子分类的一级分类 → **不可用**
- 无子分类的一级分类 → **可用**
- 所有二级分类 → **可用**

```python
def format_desc(cat, usable: bool):
    action = cat.get("action")
    usable_str = "可用" if usable else "不可用"
    if action:
        return f"id={cat.get('id')},name={cat.get('tname')},actionId={action.get('id')},handle={action.get('handle')},handleName={action.get('hname')},{usable_str}"
    return f"id={cat.get('id')},name={cat.get('tname')},actionId=null,{usable_str}"

# 一级分类：有子分类则不可用
result.append({"description": format_desc(cat, usable=not has_children), "children": children})
```

**同步更新**：
- `TYPES_DESC` - 说明可用性规则
- `ADD_FLOW_DESC` - 提示使用"可用"的分类
- `UPDATE_FLOW_DESC` - 提示使用"可用"的分类
- `easy_accounts_instructions.prompt` - 任务指导中添加分类使用规则

**文件**: `koalaq_hub/tools/builtin/easy_accounts.py`

### 2. 任务指导多文件支持

#### 问题描述

Docker Compose 映射 `./AI/task.prompt` 到 `easy_accounts_instructions.prompt`，导致用户的简单指导文件**覆盖**了核心的详细任务指导（69行）。

```yaml
# 原映射方式（会覆盖核心指导）
volumes:
  - ./AI/task.prompt:/app/koalaq_hub_python/resource/prompts/layers/task/easy_accounts_instructions.prompt
```

#### 解决方案

将 `task_instructions_file` 改为数组格式，支持多个文件按顺序加载：

```ini
# agent.ini
task_instructions_file = ["easy_accounts_instructions_inner.prompt", "easy_accounts_instructions.prompt"]
```

**加载顺序**：
1. `easy_accounts_instructions_inner.prompt` - 内部核心指导（开发者维护）
2. `easy_accounts_instructions.prompt` - 用户自定义指导（Docker 映射覆盖）

**代码修改**：

```python
# agent_builder.py - 支持数组格式和向后兼容
@property
def task_instructions_file(self) -> List[str]:
    task_file_str = self._data.get("task_instructions_file", "")
    if not task_file_str:
        return []
    try:
        files_list = json.loads(task_file_str)
        if isinstance(files_list, list):
            return files_list
        else:
            return [str(files_list)]
    except json.JSONDecodeError:
        # 向后兼容：单文件字符串
        return [task_file_str]
```

```python
# system_prompt_assembler.py - 多文件加载
def _load_task_layer(self, agent: Agent) -> str:
    if not agent.task_instructions_file:
        return ""

    contents = []
    for task_file in agent.task_instructions_file:
        task_path = self.layers_dir / "task" / task_file
        if task_path.exists():
            try:
                with open(task_path, 'r', encoding='utf-8') as f:
                    content = f.read().strip()
                    if content:
                        contents.append(content)
            except Exception as e:
                self.logger.error(f"加载任务指导文件失败 {task_file}: {e}")

    return "\n\n".join(contents)
```

- `resource/config/agent.ini`

- `koalaq_hub/models/agent.py`
- `koalaq_hub/core/agents/agent_registry.py`

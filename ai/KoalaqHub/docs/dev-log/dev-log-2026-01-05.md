### 1. VL 请求超时调整

#### 问题描述

VL（Vision-Language）模型处理多张图片时，原 4 秒超时导致请求频繁失败。

#### 解决方案

检测请求中是否包含图片，VL 请求使用 15 秒超时，普通请求保持 4 秒。

```python
# 检测 VL 请求
has_images = False
for msg in messages:
    content = msg.get("content")
    if isinstance(content, list):
        for part in content:
            if isinstance(part, dict) and part.get("type") == "image_url":
                has_images = True
                break

initial_timeout = 15 if has_images else 4  # VL 15秒，普通 4秒
```

**文件**: `koalaq_hub/core/llm/enhanced_llm_client.py`

### 3. Stream Close 兼容性修复

#### 问题描述

OpenAI SDK 的 `AsyncStream.close()` 是协程，直接调用会报警告：`coroutine was never awaited`。

#### 解决方案

创建通用的 `safe_close_stream()` 函数，自动检测并处理：

```python
async def safe_close_stream(stream) -> None:
    """安全关闭 stream，兼容协程和非协程的 close 方法"""
    if stream is None:
        return
    close_method = getattr(stream, 'close', None) or getattr(stream, 'aclose', None)
    if close_method is None:
        return
    try:
        result = close_method()
        if asyncio.iscoroutine(result):
            await result
    except Exception:
        pass
```

**文件**: `koalaq_hub/core/llm/enhanced_llm_client.py`

### 6. 滚动日志支持

#### 需求描述

Docker 环境需要持久化日志文件，并按日期滚动。

#### 实现方案

- 新增 `LOG_DIR` 环境变量配置日志目录
- 使用 `TimedRotatingFileHandler` 按日期滚动
- 日志文件命名格式：`koalaq_YYYYMMDD.log`
- 保留 30 天历史日志

```python
def setup_logging():
    log_dir = os.environ.get("LOG_DIR", "")
    if log_dir:
        log_file = log_path / f"koalaq_{datetime.now().strftime('%Y%m%d')}.log"
        file_handler = TimedRotatingFileHandler(
            filename=str(log_file),
            when="midnight",
            interval=1,
            backupCount=30,
            encoding="utf-8"
        )
```

**Docker Compose 配置**:
```yaml
volumes:
  - ./AI/logs:/app/logs
```
